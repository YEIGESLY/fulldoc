## Preguntas Frecuentes

<ExpandableGroup>
  <Expandable title="¿Cómo configuro mi primer agente de voz?" default-open="true">
    Consulta nuestra [guía para crear tu primer agente de voz](/docs/primer-agente-voz). Incluye instrucciones paso a paso para configurar el saludo, las capacidades y las integraciones básicas.
  </Expandable>
  <Expandable title="¿Qué integraciones están disponibles?" default-open="false">
    E-SMART360 se integra con Cal.com, Google Calendar, ElevenLabs, DeepGram, Groq, OpenAI, Pipedrive, Sarvam AI, TidyCal, Twilio, Make.com y Zapier. Consulta la [guía de integraciones](/docs/integracion) para más detalles.
  </Expandable>
  <Expandable title="¿Cómo pruebo mi webhook?" default-open="false">
    Utiliza nuestro [framework de pruebas](/docs/framework-pruebas-automatizacion) para generar payloads de prueba y validar tu integración antes de ponerla en producción.
  </Expandable>
  <Expandable title="¿Ofrecen planes empresariales?" default-open="false">
    Sí, tenemos planes empresariales con soporte prioritario, despliegues personalizados y SLAs garantizados. Contáctanos en ventas@esmart360.com para recibir una cotización.
  </Expandable>
  <Expandable title="¿Cómo reporto un error o problema técnico?" default-open="false">
    Revisa primero nuestra [guía de solución de problemas](/docs/solucion-de-problemas). Si el problema persiste, contáctanos a través del correo de soporte técnico con los detalles del error y los pasos para reproducirlo.
  </Expandable>
</ExpandableGroup>
